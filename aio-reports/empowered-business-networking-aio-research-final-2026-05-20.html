9. Deploy Path Overview

EBN runs on GoHighLevel (also called LeadConnector or GHL) — not WordPress. The deploy path is platform-specific: schema injects via the platform's Custom Code / Header Tracking Code field rather than via a plugin. The full step-by-step instructions live in your deploy guide; this section is the approach in plain terms.

How it goes live

  1. Validate each payload at Google's Rich Results Test before any paste-in goes live
  2. Single-block paste-in — because EBN is single-page, all 9 schema types deploy in one consolidated head injection
  3. Canonical URL fix — add a <link rel="canonical"> tag on /home pointing to / (your /home page currently serves identical content to /, splitting entity attribution)
  4. Post-deploy validation — view page source, re-test each block, confirm no errors
  5. Google Search Console submission — URL Inspection on the canonical → Request Indexing → re-crawl triggers on Google's next pass

Apollo executes all five steps live during your Zoom deploy session — you watch screen-share and confirm each step as it goes live. Sessions run 45–60 minutes.

Note on the landing-page wording. The AIO Research page references a "WordPress deployment guide." Your deploy guide is LeadConnector-specific because your site runs on LeadConnector. The done-for-you Zoom session adapts the platform-specific paste-in to your stack — same contract item, adapted to your CMS.
