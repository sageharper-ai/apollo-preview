Install and check

Use Squarespace sitewide Code Injection only for an approved business correction. Use Advanced → Page Header Code Injection for each page-specific block. Inspect Squarespace-generated Organization or LocalBusiness first, remove the invalid handwritten homepage block, and avoid duplicate IDs. Confirm each page's canonical address and visible content. Paste only the blocks assigned to that page.

After installation, inspect rendered JSON-LD and duplicate IDs, run Schema.org Validator on the live pages, check eligible features with Google Rich Results Test without assuming FAQ rich results, and check desktop and mobile pages. Record the installation date and changes. If a block conflicts, restore the saved injection code or remove that new page block, then recheck.

Leave client design hubs and their search exposure untouched without Paul's explicit approval. Recommend converting selected image testimonials to visible text only with permission; do not add Review or AggregateRating markup. Schedule the single Pulse remeasurement 30 days after execution.
